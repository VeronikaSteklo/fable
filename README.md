# Fable

Прототип текстовой RPG: опиши мир, завязку и героя, а языковая модель будет вести историю и отвечать на действия игрока. Ответы выводятся по мере генерации.

Сейчас повествованием управляет один LangChain-агент-мастер. Он может читать и обновлять состояние игры: локацию, инвентарь и установленные факты. Спутники и другие агенты пока не подключены.

## Требования

- Python 3.12 или новее
- Poetry
- OpenAI-совместимый сервер с поддержкой Chat Completions и streaming

## Установка

```bash
poetry install
cp example.env .env
```

Заполни `.env` параметрами своего LLM-сервера:

```env
BASE_URL=
API_KEY=
MODEL=
ENABLE_THINKING=none
TEMPERATURE=0.7
```

Заполни `API_KEY`, `BASE_URL` и `MODEL` значениями своего LLM-сервера. Эти обязательные поля намеренно не имеют значений по умолчанию; если оставить их пустыми, приложение подскажет, что заполнить.

`ENABLE_THINKING` принимает `none`, `low`, `medium` или `xhigh`. `TEMPERATURE` принимает число от `0` до `2`. По умолчанию thinking выключен, а temperature равна `0.7`.

Долгосрочная векторная память использует ChromaDB и включается после заполнения `EMBEDDING_MODEL` в `.env`. Укажи идентификатор модели, совместимой с OpenAI Embeddings API; если endpoint отличается от `BASE_URL`, задай `EMBEDDING_BASE_URL`. Пока модель не задана, векторные tools отключены. Воспоминания сохраняются локально в `.fable/chroma` и фильтруются по описанию кампании.

Остальные настройки, которые можно переопределить: `HISTORY_LIMIT`, `DEFAULT_WORLD`, `DEFAULT_STORY`, `DEFAULT_CHARACTER_NAME`, `DEFAULT_CHARACTER_ROLE`, `DEFAULT_CHARACTER_GOAL` и `DEFAULT_GENRE`.

## Запуск

```bash
poetry run fable
```

Следуй подсказкам в терминале, чтобы описать игру и героя. Чтобы закончить игру, введи `выход`.

## Ограничения прототипа

- Поддерживается один герой, которым управляет игрок.
- История хранится в оперативной памяти и не сохраняется после завершения программы.
- Для работы нужен доступный LLM-сервер с потоковой генерацией.
